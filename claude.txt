--- CHANGES MADE ---

1. FIXED: Same-game Elo leakage in src/features/build_team_features.py
   Bug: iterrows() processed row-by-row, updating ratings mid-game so the
   second team row received a post-result rating as its "pre-game" value.
   Fix: Deduplicate by GAME_ID, sort by date, snapshot pre-game ratings for
   BOTH teams before any update, then update once per game.
   Runtime regression test added: test_elo_leakage() asserts
     team_A.ELO_RATING == team_B.OPP_ELO_RATING for every game pair.

2. FIXED: Future leakage in src/models/season_sim.py load_season_schedule()
   Bug: bfill().ffill() — backward fill pulled values from later games in the
   same season into early-season rows.
   Fix: Replaced with ffill() only (forward-fill within team), then filled
   any remaining NaN with documented neutral defaults:
     ROLL_WIN_PCT=0.5, ROLL_POINT_DIFF=0.0, DAYS_SINCE_LAST_GAME=3.0,
     ROLL_EFG/OPP=0.52, ROLL_TOV_PCT/OPP=0.13, ROLL_ORB_PCT/OPP=0.25,
     ROLL_FTR/OPP=0.20, ROLL_EFG_DIFF=0.0, SEASON_POINT_DIFF=0.0,
     EMA_POINT_DIFF=0.0
   Runtime regression test added: test_no_future_leakage() checks the first
   game of each loaded season received exactly 0.5 for ROLL_WIN_PCT (not a
   later-game derived value).

3. NEW FILE: src/models/walk_forward_backtest.py
   Full walk-forward backtest engine:
   - For each target season, trains strictly on SEASON_YEAR < target.
   - Hard assert: zero target-season rows in training set.
   - Actual wins computed from full feature table (all games, tanking retained).
   - Tanking flag exclusion applies to training rows only (--exclude-tanking-flags).
   - Fixed seed=42, 1000 simulations per season.
   - Outputs CSV: data/processed/walk_forward_backtest_results.csv
     or walk_forward_backtest_results_no_tanking.csv

4. NEW FILE: scripts/compare_tanking_backtests.py
   Loads both walk-forward CSVs, merges on SEASON+TEAM, asserts actual wins
   are identical between runs, and reports overall/top-5/bottom-5 MAE + deltas.
   Saves: data/processed/walk_forward_comparison.csv

--- REMAINING KNOWN ISSUES ---

* Top/bottom-5 MAE is ~4.8-4.9 wins in walk-forward vs ~3.3 overall,
  confirming the model still under-predicts elite teams and over-predicts bad
  teams (the extremes-compression bias documented in PLAN.md). This is a
  known open issue, not introduced by today's changes.
* Walk-forward MAE (3.34) is higher than Phase 3 MAE (2.47) because Phase 3
  used train_test_split on the full pool (mild temporal leakage). Walk-forward
  is the methodologically correct figure.
* 2015-16 cannot be a target season (no prior training data); first evaluable
  fold is 2016-17 with only one prior season of training data.
